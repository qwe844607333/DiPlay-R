# DiPlay v0.3.14 — 认证加固与矩形车机直角显示

本版修复未完成 CarPlay 身份验证时提前建立媒体、控制或 iAP2 通道的问题。现在 SETUP、RECORD、TEARDOWN、缓冲音频控制、画面/模式命令、反馈和事件通道都要求已完成 pair-verify；未验证连接会收到 `401 Unauthorized`。正常 iPhone 首次配对、自动重连、音视频和触控流程保持不变，视频队列与帧率处理未修改。

矩形车机默认启用“强制直角显示”：CarPlay 不再声明触发 iOS 圆角遮罩的 `safeArea`，Android 视频视图也关闭轮廓裁切，画面可铺满长方形车机屏幕。设置中的开关仍可手动关闭，显式选择会被保留，下次连接 CarPlay 时生效。

同包名及个人维护签名，versionCode 134，可覆盖升级此前个人版。完整离线 CI 与个人签名构建通过，不代替真实 iPhone 和车机的连接、音视频、触控及重连验证。
