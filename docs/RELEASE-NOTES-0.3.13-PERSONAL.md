# DiPlay v0.3.13 — 60帧优化、平稳恢复与影豹R车机图标

现场 0.3.12 日志中，30 fps 会话也出现反复积压恢复与现有 Wi-Fi 丢失。本版调整恢复方式，减少应用在短暂过载时主动制造的停顿。

- 软积压先请求关键帧并继续有效参考链；有新 IDR/IRAP 已在队列时，直接从最新独立画面恢复，保留对应配置、Surface 及后续依赖帧。持续过载仍保留硬限兜底。
- 流畅视频关闭时，超过 150 ms 的已解码输出若已有更新输出可替代，可跳过显示；最后一张画面仍正常提交，不任意丢弃压缩预测帧。每次输出处理有数量上限。
- 现有 Wi-Fi 的丢失或地址变化先核验 1500 ms。原 Network 与已公布地址恢复时保留会话；持续失效或 Network 替换仍重连。新增 IPv6 地址本身不再强制重连。
- 新增 skippedOutputs、catchUpFrames 诊断计数，不将跳过显示的画面计入 shown；关键帧扫描避免复制视频数据。
- 默认车机按钮改为“影豹R”和根据用户参考图重绘的红色 R。旧的未自定义 BYD 默认名称一次性迁移，已自定义的名称、图标继续保留。矢量母版和 2048px 图另行交付，协议内嵌图标维持 192px / 32KB 限制。
- 新安装默认请求 60 fps；升级保留已保存帧率，当前为 30 fps 时需在显示设置改为 60 并重连。

本机目标为动态场景稳定接近 60 fps。建议 H.264 / 60 fps / 80% / 硬件图层开启，流畅视频和按帧率请求解码性能关闭。若仍过载，保持 60 fps，单独将分辨率降一档对照；30 fps 仅作排障对照。无需强制全部 CPU 核心或增加虚拟内存。

同包名及个人维护签名，versionCode 133，可覆盖此前个人版。源码测试与构建验证不代替真实车机对照；本版不保证恒定 60 fps，也无法修复盒子供电或持续无线物理断链。
