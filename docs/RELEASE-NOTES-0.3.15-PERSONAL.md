# DiPlay v0.3.15 — 自定义名称、离线更新与视频接收优化

iPhone 端 CarPlay/iAP2 显示名称改为跟随“设置 → 车辆 → CarPlay 中的车辆按钮 → 名称”，不再固定显示 DiPlay。修改名称并重新连接 CarPlay 后生效。

本维护版本关闭在线更新：移除自动和手动检查、GitHub 更新后端、下载安装流程、更新证书及相关资源，运行时不再访问原始 GitHub 更新渠道。

CarPlay 视频 TCP 接收缓冲提高到 4 MB，降低突发视频帧在接收端排队的概率。实时日志显示卡顿主要与 iPhone 视频帧到达间隔有关，不建议强制分配更多 CPU 核心。

圆角显示保持现状。同包名及个人维护签名，versionCode 135，可覆盖升级此前个人版。完整 CI 通过，但本文件对应测试包需要实车确认名称、连接、滑动、音视频和触控。
